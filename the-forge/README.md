# The Forge — Brand & Poster

Redesigned advertisement for **The Forge, Cohort One** (September – December 2026).
Direction: high-end, gritty, editorial — pure typography on ink black, one ember
accent, film grain and a printer's frame instead of AI-generated imagery.

## Files

| File | Purpose |
|---|---|
| `poster.html` | Master artwork. Self-contained (fonts self-hosted in `fonts/`). Open in Chrome and print at "Actual size" to export any format. |
| `poster.pdf` | Print-ready PDF (A4-proportioned, full bleed). |
| `poster-print.png` | ~300 dpi raster for print or high-res sharing. |

## Brand scheme

**Palette**

| Token | Hex | Use |
|---|---|---|
| Ink | `#0e0c09` | Background — warm near-black, never pure black |
| Bone | `#e8e1d3` | Primary type — warm off-white, never pure white |
| Ember | `#c8571f` | Accent fills, rules, the closing bar |
| Ember hot | `#d96f32` | Accent type on dark, CTA outline |

One accent colour only. If it isn't ink, bone, or ember, it isn't on brand.

**Type**

| Role | Face | Notes |
|---|---|---|
| Display / wordmark | Anton | All caps, tight leading (0.82–1.18) |
| Emotional emphasis | Instrument Serif Italic | Lowercase, contrast against Anton |
| Labels / data | IBM Plex Mono | All caps, wide tracking (0.3em) |
| Body | Archivo | Sentence case, muted bone at 62% opacity |

**Texture** — SVG fractal-noise grain at 50% overlay + soft vignette + a single
warm radial glow. No photography unless it's a real, commissioned shot of the
actual gym/men — never stock or generated imagery.

**Voice** — short declaratives ("Twelve men only."), sections named like a
contract: *The Terms, The Investment, The Door.*
